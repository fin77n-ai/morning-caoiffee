🧠 AI Term of the Day

HNSW (Hierarchical Navigable Small World) 索引

一种用于近似最近邻搜索的算法，构建多层图结构来加速向量检索。想象城市的道路网络：高速路（上层）让你快速跨越长距离，社区小路（下层）精确定位。ChromaDB、Pinecone、Qdrant 都用它做快速向量检索，是 RAG 系统中"检索"环节的幕后英雄。

from chromadb import Client
client = Client()
collection = client.create_collection(
    "my_docs",
    metadata={"hnsw:space": "cosine", "hnsw:M": 16, "hnsw:ef_construction": 200}
)
collection.add(embeddings=my_vectors, ids=my_ids)
💭 今日好奇
DuckDB 现在能当远程数据库用了，那 RAG pipeline 的架构会被改写吗？

以前我们的 RAG 数据层往往是"本地 DuckDB 做 ETL → 远程 PostgreSQL 或向量数据库存生产数据"的割裂状态。现在 Quack 协议让 DuckDB 实例之间可以远程通信、并发写入，能不能把整个 RAG 数据栈统一在 DuckDB 里？本地 embedding + 远程向量搜索 + 同一套 SQL 语法……想想就兴奋。当然，生产环境的并发和稳定性还有待验证，但方向太诱人了。
